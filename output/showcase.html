Design Notes
07

4-Color Pastel System

Teal (primary UI), orange (actions), yellow (highlights), magenta (movement/mood). All as soft as each hue allows.

Theme-Ready Structure

All colors live in CSS custom properties. Swapping themes means updating ~12 variables. Two alt palettes shown: Peach Blossom and Lavender Dream.

3 Font Options

Nunito (current, rounded/friendly), Quicksand (geometric/modern), Rubik (clean/sturdy). All loaded via Google Fonts, ready for a font picker.

Semantic Color Roles

Chat = teal, actions = orange, movement = magenta. The yellow is reserved for future highlights, notifications, or warnings.

Dark Base, Soft Accents

Dark blue-grey background lets pastels pop without feeling washed out. Surface and card tones are neutral, not tinted.

All Pastel, Nothing Whacky

Every color stays in the soft/muted pastel range. No neon, no saturated, no harsh contrasts. Cozy game UI feel throughout.
